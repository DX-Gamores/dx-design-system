Motion

Fast, purposeful, and off when asked. Reduced mode sets every duration to 0 and easing to linear — no extra work per component.

Durations

duration/instant100 ms · toggles, checkboxes
duration/fast150 ms · hover, press
duration/moderate250 ms · menus, tooltips
duration/slow350 ms · dialogs, drawers

Easing

easing/standardcubic-bezier(0.2, 0, 0, 1)
easing/entercubic-bezier(0, 0, 0.2, 1)
easing/exitcubic-bezier(0.4, 0, 1, 1)

Standard for things that move within the screen, enter for things arriving (decelerate), exit for things leaving (accelerate).

Springs New · v3.2.0

Physics-based timing for things that move with the hand or need to feel alive. Each spring ships as a CSS linear() curve; Reduced mode makes them instant.

snappystiffness 400 · damping 30 · ~450 msToggles, chips, small state changes
gentlestiffness 170 · damping 26 · ~730 msPanels, sheets, menus opening
bouncystiffness 300 · damping 15 · ~950 msRare delight: success, a new item landing

Sequential & diverging

Order and direction, not categories.

Sequential
12345
One hue, darker = more. Flips in dark mode so “more” still stands out.
Diverging
neg-2neg-1midpos-1pos-2
Orange below the midpoint, blue above — never red/green.

Pick the palette

What does the data look like?

Separate categories?→ Categorical · series-1…8e.g. Tickets by channel, revenue by region
Ordered values, low → high?→ Sequential · 1…5e.g. Heatmaps, usage intensity, density maps
Above and below a midpoint?→ Diverging · neg / mid / pose.g. Change vs. last month, sentiment, budget variance

Chart anatomy

The quiet parts have tokens too.

  • dataviz/gridlineGridlines whisper
  • dataviz/axisAxes speak
  • dataviz/labelLabels stay readable (≥ 4.5:1)
  • dataviz/series-1Data shouts
  • Lines are labelled directly at their ends, so the chart works without a legend.

Tokens

21 tokens in the Color collection, all aliasing Primitives per mode. Values below are for the current theme.

In code

import { dataviz } from "@dxform/design-system/tokens";
dataviz.series;      // 8 categorical colours as CSS variables, use in order

In Tailwind: bg-viz-series-1, fill-viz-series-1, stroke-viz-axis. For canvas charts, read the current value with readToken("--ds-color-dataviz-series-1").

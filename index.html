How it's built

Follow one colour from raw value to button. Each layer only points at the layer before it. Designers and components use layer 3 — never raw values.

  1. Layer 1 →Primitivecolor/blue/600Raw palette value. Hidden from pickers.
  2. Layer 2 →Brandbrand/primary/600Default = blue · Violet = violet · Amber = amber.
  3. Layer 3 →Semanticcolor/bg/brandNamed by purpose. Has Light, Dark and HC values.
  4. Layer 4Componentbutton/primary/bgWhat ships. Re-skins when any layer changes.

Four rules

Tokens before pixelsUsed twice? It becomes a token. No hex or px in components.
Semantic over rawName by purpose, not appearance. Meaning survives rebrands.
Accessible by defaultText ≥ 4.5:1, UI ≥ 3:1, visible focus everywhere.
Start small, grow deliberatelyShip the minimum, learn, then add — through the changelog.

List Item

Coded4 variants in Figma

One row in a simple list (members, files, notifications). Replaces hand-built rows from the v0.4.1 agent test.

Properties

Property notes

State (Default | Hover | Selected | Focus) · Title, Description · Show leading (Avatar, exposed — swap for an icon if needed) · Show meta (Badge, exposed) · Show action (Icon Button, exposed; set Accessible label per row). · Trailing (slot: badge, toggle, price, custom controls)

Text

Title and description wrap (never clip); keep descriptions to one sentence.

Layout

Stack items with a Divider between them inside a bg/surface + border/default + radius/lg container. Padding padding/card × padding/row (density-aware). Need columns, sorting or comparison → Table.

Code

<List label="…"><ListItem title="…" description="…" leading={<Avatar …/>} meta={<Badge …/>} action={<Menu …/>} /></List>

Table Header Cell

Coded4 variants in Figma

Column header. Sort: None (sortable, unsorted) · Ascending · Descending · Not sortable.

Properties

Figma property Type Options / default Suggested React prop
Label Text Name label
Sort Variant None · Ascending · Descending · Not sortable sort

Accessibility

<th scope="col"> with aria-sort on the sorted column only; the label is a button that toggles sort. Resize width to the column; use the same width for every cell in that column.

Code

<Table columns={[{ key, header, sortable, render }]} sort={{ key, direction }} … />  (header cell)

Table Cell

Coded8 variants in Figma

One cell in a data table row. Types: Text · Two-line · Avatar (person) · Badge (status) · Numeric (right-aligned, tabular) · Checkbox (row selection, 48px) · Actions (Icon Button "More", 64px).

Properties

Figma property Type Options / default Suggested React prop
Value Text Editor value
Secondary Text jane@acme.com secondary
Cell content Slot — cellContent
Type Variant Text · Two-line · Avatar · Badge · Numeric · Checkbox · Actions · Custom type

Notes

COMPOSE A TABLE: a header row of Table Header Cells, then rows = horizontal auto-layout frames of Table Cells with matching widths (fill the flexible column) and EVERY body cell set to Fill height, so bottom borders line up (header cells keep their fixed size/control-md height). Row hover = color/bg/neutral-hover; selected row = color/bg/brand-subtle. Wrap in bg/surface + border/default + radius/lg, clip content.

Accessibility

Real <table> with a caption/accessible name; checkbox cells label "Select <row name>"; action Icon Buttons include the row name ("More actions for Jane Cooper"). On Mobile, switch a table to List Items unless columns are essential.

Code

<Table caption="…" columns={[…]} rows={…} rowKey={…} />  (cells via column render)

Pagination

Coded1 variant in Figma

Moves through pages of a table or list. Summary text (what is shown) + previous/next Icon Buttons (Secondary, Small; Disabled at the ends) + current page. <nav aria-label="Table pagination">; announce the new range in a polite status message after paging.

Properties

Figma property Type Options / default Suggested React prop
Summary Text Showing 1–10 of 48 summary
Page Text Page 1 of 5 page

Code

<Pagination page={1} pageCount={5} summary="Showing 1–10 of 48" onPageChange={…} />

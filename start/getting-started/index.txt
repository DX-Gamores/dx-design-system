b:T1910,<h2>0. Install</h2>
<p>Add the kit to any web project straight from GitHub (or copy the <code>dist/</code> folder):</p>
<pre><code class="language-bash">npm i github:DX-Gamores/dx-design-system
</code></pre>
<pre><code class="language-css">/* app/globals.css */
@import &quot;tailwindcss&quot;;
@import &quot;@dxform/design-system/tokens.css&quot;;
@import &quot;@dxform/design-system/tailwind.css&quot;;
</code></pre>
<pre><code class="language-html">&lt;html data-brand=&quot;default&quot; data-theme=&quot;light&quot; data-density=&quot;comfortable&quot;&gt;
</code></pre>
<p>Components live in <a href="https://github.com/DX-Gamores/dx-design-system/tree/main/src/components/ui"><code>src/components/ui</code></a>. Copy the ones you need into your project and own them (the shadcn/ui approach). They only depend on the tokens, so they re-skin for any brand. To start a new app, copy <code>src/app/starter</code> as well.</p>

<h2>2. Themes, brands, density</h2>
<p>Set these attributes on <code>&lt;html&gt;</code>, or on any wrapper (always put both brand and theme on the same element):</p>
<div class="ds-table"><table>
<thead>
<tr>
<th>Attribute</th>
<th>Values</th>
<th>Figma collection</th>
</tr>
</thead>
<tbody><tr>
<td><code>data-brand</code></td>
<td><code>default</code> · <code>violet</code> · <code>amber</code></td>
<td>Brand</td>
</tr>
<tr>
<td><code>data-theme</code></td>
<td><code>light</code> · <code>dark</code> · <code>light-hc</code> · <code>dark-hc</code></td>
<td>Color</td>
</tr>
<tr>
<td><code>data-density</code></td>
<td><code>comfortable</code> · <code>compact</code></td>
<td>Dimension</td>
</tr>
<tr>
<td><code>data-motion</code></td>
<td><code>default</code> · <code>reduced</code></td>
<td>Motion</td>
</tr>
</tbody></table></div>
<p>These follow the device automatically:</p>
<ul>
<li><strong>No <code>data-theme</code>:</strong> it follows the system dark mode and &quot;increase contrast&quot; settings.</li>
<li><strong>No <code>data-motion</code>:</strong> it follows &quot;reduce motion&quot;.</li>
<li><strong>Typography and layout:</strong> they follow the breakpoints (Desktop ≥ 1024, Tablet 600–1023, Mobile &lt; 600, Wide ≥ 1440), like the Figma Typography and Layout modes.</li>
</ul>
<h2>3. Building a component</h2>
<ol>
<li>Open its spec in <code>docs/components/&lt;name&gt;.md</code>. It covers when to use it, its properties, tokens, keyboard behaviour and code API.</li>
<li>Look at the Figma page in view-only mode for the visual states. The &quot;Every state, side by side&quot; matrix shows each one.</li>
<li>If a coded version exists in <code>src/components/ui</code>, use or extend it. If not, build it from tokens only, following the spec.</li>
<li>Check it on its docs-site page and in the <a href="https://dx-gamores.github.io/dx-design-system/start/gallery/">component gallery</a> in every brand × theme, plus keyboard-only.</li>
</ol>
<h2>4. App-level setup</h2>
<p>Most components need nothing. Two need one line each:</p>
<pre><code class="language-tsx">// app/layout.tsx — toasts render in one shared live region
import { ToastProvider } from &quot;@/components/ui&quot;;
&lt;body&gt;&lt;ToastProvider&gt;{children}&lt;/ToastProvider&gt;&lt;/body&gt;
</code></pre>
<ul>
<li><strong>Toast:</strong> call <code>const toast = useToast(); toast.show({ message: &quot;Saved&quot;, tone: &quot;success&quot; })</code> anywhere inside the provider.</li>
<li><strong>Dialog / Drawer:</strong> use the native <code>&lt;dialog&gt;</code> element, so the page behind is inert and focus is trapped with no extra setup. Control them with <code>open</code> and <code>onClose</code>.</li>
</ul>
<h2>5. Fonts</h2>
<p>The fonts for the three brands are self-hosted with Fontsource (<code>src/app/fonts.ts</code>): Inter, Manrope, Poppins and Roboto Mono. Delete the ones your brand doesn&#39;t use.</p>
<h2>6. Updating when design changes</h2>
<p>You never edit <code>dist/</code> or <code>docs/components/</code> by hand. When design publishes a change, the export in <code>figma/</code> is refreshed and <code>npm run build:all</code> regenerates everything (see <a href="/dx-design-system/start/workflow/">WORKFLOW.md</a>).</p>

b:T980,<p>Every component reads colours, fonts and corner radius from the <strong>Brand</strong> layer, so a new brand is one new mode, not a redesign.</p>
<h2>In Figma (design, one seat)</h2>
<ol>
<li>In <strong>Variables → Brand</strong>, add a mode, e.g. <code>Client · Acme</code>.</li>
<li>Set its values:<ul>
<li><strong>primary:</strong> the 50–950 ramp. Pick from Primitives, or add a new ramp to Primitives first.</li>
<li><strong>accent and neutral:</strong> their ramps.</li>
<li><strong>font-family:</strong> heading and body.</li>
<li><strong>shape:</strong> the control and container radius.</li>
</ul>
</li>
<li>Check the <strong>Themes &amp; Brands</strong> page: switch any frame to the new mode and look at all four colour modes.</li>
<li>Ask Claude to run the release audit, including the contrast check across brands × modes, then publish.</li>
</ol>
<h2>In code</h2>
<ol>
<li>Re-export the variables (see <a href="/dx-design-system/start/workflow/">WORKFLOW.md</a>) and run <code>npm run tokens</code>.</li>
<li>The build adds a <code>[data-brand=&quot;…&quot;]</code> block to <code>dist/tokens.css</code>. Add its name to the selector map at the top of <code>scripts/build-tokens.mjs</code> (<code>brandSel</code>) and to <code>brands</code> in <code>dist/tokens.ts</code>.</li>
<li>Load the brand&#39;s font in <code>src/app/fonts.ts</code>.</li>
<li>Set <code>&lt;html data-brand=&quot;acme&quot;&gt;</code>. Nothing else changes.</li>
</ol>
<h2>Quick option, no Figma change (prototypes only)</h2>
<p>Override the brand ramp in your app&#39;s CSS:</p>
<pre><code class="language-css">[data-brand=&quot;acme&quot;] {
  --ds-brand-primary-50: #f0f7ff;   /* … through 950 */
  --ds-brand-primary-600: #0057b8;
  --ds-font-family-heading: &quot;Acme Sans&quot;, system-ui, sans-serif;
  --ds-font-family-body: &quot;Acme Sans&quot;, system-ui, sans-serif;
}
</code></pre>
<p>Bring it back into Figma before it ships, so design and code stay in sync.</p>
<h2>Contrast checklist for a new brand</h2>
<ul>
<li><code>brand/role/solid</code> (buttons, selected states) against white text is <strong>≥ 4.5:1</strong>.<ul>
<li>If it isn&#39;t, set <code>on-solid</code> to dark text. The amber brand does this.</li>
</ul>
</li>
<li>In the HC modes, <code>solid-hc</code> is <strong>≥ 7:1</strong>.</li>
<li>Focus ring (<code>brand/role/focus</code>) against the surface is <strong>≥ 3:1</strong>.</li>
</ul>
